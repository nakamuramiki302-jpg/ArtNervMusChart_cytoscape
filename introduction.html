💻 よく使われたコード例

1. 検索機能の実装

ユーザーが入力した検索語を使って、解剖学用語を検索する機能です。

function directSearch() {
    const searchInput = document.getElementById('search-input');
    const query = searchInput.value;
    
    // 検索結果を格納する配列
    const results = [];
    
    // 全てのノードを検索
    cy.nodes().forEach(function (node) {
        const name = node.data('name').toLowerCase();
        if (name.includes(query.toLowerCase())) {
            results.push({
                id: node.id(),
                name: node.data('name'),
                type: node.data('type')
            });
        }
    });
    
    // 検索結果を表示
    updateSearchResults(results);
}

解説： この関数は、入力された検索語と一致する解剖学用語を見つけて、結果を表示します。

2. 円状配列の実装

選択されたノードの周りに、関連するノードを円状に配置する機能です。

function arrangeInCircle(centerNode, neighbors) {
    const centerX = cy.width() / 2;
    const centerY = cy.height() / 2;
    const radius = 150;
    
    // 中心ノードを配置
    centerNode.position({ x: centerX, y: centerY });
    
    // 隣接ノードを円状に配置
    neighbors.forEach(function (neighbor, index) {
        const angle = (index / neighbors.length) * 2 * Math.PI;
        const x = centerX + radius * Math.cos(angle);
        const y = centerY + radius * Math.sin(angle);
        
        neighbor.position({ x: x, y: y });
    });
}

解説： 数学の三角関数を使って、ノードを美しい円状に配置します。

3. 色分け機能

解剖学的な種類に応じて、ノードに異なる色を適用する機能です。

function applyAnatomyColors() {
    const anatomyColors = {
        muscle: { background: '#F8BBD9', border: '#E91E63' },
        artery: { background: '#FFCDD2', border: '#D32F2F' },
        nerve: { background: '#C8E6C9', border: '#388E3C' }
    };
    
    cy.nodes().forEach(function (node) {
        const nodeType = getNodeType(node);
        const colors = anatomyColors[nodeType];
        
        node.style({
            'background-color': colors.background,
            'border-color': colors.border,
            'border-width': '2px'
        });
    });
}

解説： 筋肉はピンク、動脈は赤、神経は緑など、種類に応じて色を変えることで、視覚的に分かりやすくします。

4. モバイル対応

スマートフォンでのタッチ操作に対応する機能です。

function handleSearchResultClick(element) {
    // マウスクリックとタッチの両方に対応
    const resultId = element.getAttribute('data-result-id');
    const resultName = element.getAttribute('data-result-name');
    
    // タッチ時の視覚的フィードバック
    element.style.backgroundColor = '#e3f2fd';
    
    // 選択されたノードをハイライト
    highlightSelectedNode(resultId, resultName);
    
    // タッチハイライトを解除
    setTimeout(() => {
        element.style.backgroundColor = '';
    }, 200);
}

解説： スマートフォンでタッチした時に、視覚的なフィードバックを提供し、使いやすさを向上させます。
